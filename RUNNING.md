# Hospital Management System - Remix + MongoDB\n\n## Quick Start\n\n1. **Start MongoDB**\n   ```bash\n   docker-compose up -d\n   ```\n\n2. **Install dependencies**\n   ```bash\n   npm install\n   ```\n\n3. **Set up environment**\n   ```bash\n   cp .env.example .env\n   ```\n\n4. **Seed the database**\n   ```bash\n   npm run seed\n   ```\n\n5. **Start dev server**\n   ```bash\n   npm run dev\n   ```\n\n6. **Open in browser**\n   http://localhost:3000\n\n## Using MongoDB Compass\n- Connect to: `mongodb://localhost:27017`\n- Database: `hms`\n- Collections: patients, doctors, appointments, staff, invoices\n\n## Demo Login\n- Username: `admin`\n- Password: `admin123`\n
